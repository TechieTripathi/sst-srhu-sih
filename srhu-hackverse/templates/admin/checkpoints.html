About Evaluation Checkpoints

Purpose
Evaluation checkpoints allow you to organize the judging process into multiple stages (e.g., Initial Screening, Semi-Finals, Final Presentation). Each stage tracks evaluations independently.
Active Stage
Only one stage can be active at a time. The active stage determines which checkpoint judges are currently evaluating. Set a stage as active before judges begin evaluations for that checkpoint.
Judging Lock
The judging lock is a global control that prevents ALL evaluation submissions across all stages. Use this when you need to freeze the system for results calculation or when the evaluation period officially ends.
